# TaskBoard

Task management API built with ASP.NET Core Minimal APIs, Entity Framework Core, and SQL Server.  
An Angular frontend is planned next.

## Tech stack

- .NET 10 / ASP.NET Core Minimal APIs
- Entity Framework Core + SQL Server
- JWT authentication (BCrypt password hashing)
- Swagger / Swashbuckle
